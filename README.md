# Better Midsayap

A community-run portal for **Midsayap, Cotabato**: municipal officials, offices, services and public information in one place.

Better Midsayap is a volunteer project listed in the [BetterGov.ph LGU Directory](https://lgu.bettergov.ph/). It is **not** an official website of the Municipality of Midsayap.

## About Midsayap

Midsayap is a municipality in the landlocked province of Cotabato in the Soccsksargen region of Mindanao, about 32 km from Cotabato City by PhilAtlas's measure. It serves as a commercial and trading center for farm products such as rice, corn and mango from nearby towns, and holds the Halad sa Santo Niño Festival every third Sunday of January. It has 57 barangays and a population of 165,376 (2020 Census).

## Run it locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

Site content lives in `content/` (Markdown and YAML) and `src/data/`. See [CONTENT-MANAGEMENT.md](CONTENT-MANAGEMENT.md) for how to edit pages without touching code.
